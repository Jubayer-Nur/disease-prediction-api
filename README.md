# Heart Disease Prediction API

A FastAPI-based API that predicts heart disease presence using a Random Forest classifier.

## Features

- **GET /health**: Health check endpoint
- **GET /info**: Model information and feature list
- **POST /predict**: Predict heart disease from clinical features

## Technology Stack

- FastAPI (Python 3.11)
- scikit-learn (Random Forest)
- Docker & Docker Compose
- Deployed on Render
